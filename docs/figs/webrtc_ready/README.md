# Figure `webrtc_ready`: mobile browser client

## Blur private information in GIMP

1. Take screenshots of the mobile browser client.
2. Open each screenshot in GIMP.
3. Select the **Rectangle Select** tool and draw a box around the area to blur. Hold **Shift** while selecting to add multiple areas at once.
4. Apply **Filters > Blur > Gaussian Blur**, using a radius of around 40 px.
5. Export/overwrite the image.

## Compose the figure in Inkscape

1. Import the blurred screenshots into an SVG file for further editing (e.g. layout, labels, annotations).
2. Edit figue in inkscape:
```bash
inkscape webrtc_ready_in_brave_mobile_browser.svg
```
